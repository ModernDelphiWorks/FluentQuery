IFluentQueryable<T> API reference

IFluentQueryable<T> is a value record in FluentQuery.Queryable that builds and executes SQL queries through a FluentSQL AST and a DataEngine connection.

note

Method bodies are compiled only when {$DEFINE QUERYABLE} is active.

Expression factory​

function QE: IFluentQueryExpression;

Returns a typed expression builder scoped to the current database dialect.

var LQ: IFluentQueryable<TProduct>;
// ...
var LExpr := LQ.QE.Field('PRICE').GreaterThan(50.0);
LQ := LQ.Where(LExpr);

IFluentQueryExpression operators​

IFluentQueryExpression (unit FluentQuery.Expression) constructs typed SQL predicates:

MethodSQL fragment

Equal(AValue)field = value

Values are overloaded for Integer, Extended, string, TDate, TDateTime, TGUID.
